# Basic SQL Query on MySQL Database Using Python

This Python program demonstrates how to connect to a MySQL database and perform a basic SQL query.

## Features

- Connects to a MySQL database
- Executes a simple `SELECT` query
- Retrieves records from a table
- Displays formatted output
- Handles connection errors
- Closes database resources properly

## Requirements

Install MySQL connector before running the program:

```bash
pip install mysql-connector-python
